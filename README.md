# Ritmo

Central pessoal para organizar a vida: tarefas da semana, hábitos, segundo cérebro (notas), financeiro com cartões, agenda e conteúdo.

- Página única (`index.html`), sem build.
- Dados salvos no Supabase com login por e-mail e senha; cada pessoa só acessa a própria linha (RLS).
- Publicado pelo GitHub Pages.
